# Wanderly — Travel Website

A responsive static travel inspiration website built with HTML, CSS and vanilla JavaScript.

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in your browser.

## Publish using GitHub Pages
1. Create a **public** repository on GitHub, for example `wanderly-travel`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a minute or two. Your website will be available at:
   `https://YOUR-GITHUB-USERNAME.github.io/wanderly-travel/`

## Images and external services
The design uses publicly hosted Unsplash image URLs and Google Fonts. An internet connection is needed for those remote assets to load. The newsletter form is a front-end demo only; it does not store email addresses or send messages.

## Customize
- Edit text and destinations in `index.html`.
- Change colors, spacing and layout in `style.css`.
- Add interactions in `script.js`.
